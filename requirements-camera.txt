# RealSense D435i libraries.
#
# Linux / Ubuntu 24.04 (the NUC deployment target)
#   The pip wheel below is all that is needed; no source build, no Librealsense
#   apt package. Verified on the NUC with Python 3.12.
#       pip install -r requirements.txt      # includes pyrealsense2
#   Then confirm the camera is visible to the service user:
#       python -c "import pyrealsense2 as rs; print(len(list(rs.context().query_devices())))"
#   A 0 here is a USB/permission problem, not a code problem. The udev rules in
#   deploy/udev fix the permission half.
#
# macOS (the older Mac field machine)
#   Same package, different distribution name:
#       pip install pyrealsense2-macosx
#   The colour sensor is only reachable from a root process there, which is why
#   deploy/launchd runs the capture daemon as root. On Linux none of that is
#   needed, which is why the NUC build is simpler.
